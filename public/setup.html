MindMesh AI Studio Pro Setup

This in-app checklist covers the production connection. The repository README contains the complete guide.

1. Public browser variables

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_ANON_KEY
VITE_DEMO_MODE=false

2. Protected server secrets

npx supabase secrets set claude_api_key=...
npx supabase secrets set GOOGLE_API_KEY=...

Never prefix provider keys with VITE_.

3. Deploy

npx supabase db push
npx supabase functions deploy generate-text
npx supabase functions deploy generate-image
npx supabase functions deploy generate-video
npx supabase functions deploy video-status
